## 2. [PERSON_NAME], найденные в этом проходе (уже исправлены)

1. **Интерфейс тормозил из-за `localhost`.** Сервер слушает [PERSON_NAME], а браузер/клиенты шли через `localhost` → [PERSON_NAME] IPv6 → **+2 с на каждый запрос**.
   Было: `/api/state` 2.35 с, `/api/stats` 2.18 с, `/api/job` 2.05 с.
   Стало (bind [PERSON_NAME] + URL [PERSON_NAME]): **0.067 с / 0.14 с / 0.017 с**.
2. **`/api/state` пересчитывал всё на каждый вызов**: скан диска (16 моделей) + PowerShell-опрос GPU (~270 мс) при каждом заходе. Добавлены кэши: модели — 5 с, GPU — 60 с.
3. **Голос: `[object Object]` вместо текста.** Роут отдавал весь dict из `transcribe` в поле `text`. Теперь отдаёт строку; распознанное **сначала попадает в поле ввода**, отправка — по кнопке.
4. **Точность распознавания.** Добавлены: модель `large-v3-turbo-q5_0` (574 МБ) как основная, `-bs 5 -bo 5` (beam search), `--prompt` со словарём домена, язык из настроек. Проверено: SAPI→whisper распознаёт фразу без ошибок (en), турбо и base.
5. **Пути в стиле Linux** (`/home/user`) — теперь маппятся на домашнюю папку, ошибка перечисляет разрешённые корни.

## 4. Бэклог с приоритетами

**P0 — безопасность и стабильность (≈2 дня)**
1. Токен-аутентификация локального API (2–3 ч).
2. Подтверждение опасных вызовов: диалог «агент хочет записать файл / выполнить команду» (4–6 ч).
3. Отмена генерации из интерфейса (3 ч).
4. Компакция контекста по токенам + лимит шагов на задачу (4 ч).
5. Валидация JSON и человеческие тексты ошибок на всех роутах (2 ч).

**P1 — польза и глубина (≈2 недели)**
6. RAG по папкам и проектам с цитатами.
7. [PERSON_NAME] у роли (колонка «Модель»): перед шагом — переключение модели.
8. Портатив: данные рядом с программой + embedded Python (сборка папки).
9. Голос: VAD (авто-стоп по тишине), словарь терминов, выбор языка, «повторить распознавание».
10. MCP-каталог с описаниями и лимитами; разрешения на уровне отдельного инструмента.
11. Планировщик: «каждый день в 9 — сводка по папке» (cron внутри приложения).

**P2 — экосистема (месяц+)**
12. Магазин инструментов/плагинов (свой формат + MCP).
13. Параллельный fan-out ролей с бюджетом токенов и таймлайном.
14. Мобильный клиент (PWA/тонкий веб-клиент на телефон по локальной сети).
15. Синхронизация чатов/проектов между устройствами без облака.
