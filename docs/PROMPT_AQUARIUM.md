# Промт для локальной модели: 3D-аквариум (HTML + WebGL)

Скопируйте блок ниже целиком в чат агента (режим «Агент», модель любая 7B+ с кодом).

---

Сделай **один самодостаточный HTML-файл** `aquarium.html` — интерактивный 3D-аквариум на WebGL.
Требования жёсткие, без заглушек и без «// TODO».

**Технологии**
- Подключи Three.js как ES-модуль через importmap с unpkg (`three@0.160.0`), без сборщиков и npm.
- Вращение сцены реализуй сам (перетаскивание мышью + колесо для зума), сторонние контролы не подключай.
- Один файл: HTML + CSS + JS внутри. Никаких внешних картинок и текстур — только геометрия и материалы.

**Сцена**
1. Стеклянный аквариум: прозрачные стенки (MeshPhysicalMaterial, transmission/opacity), дно из гравия (много мелких сфер разных оттенков), уровень воды — полупрозрачная плоскость с лёгкой рябью.
2. Замок: башни-цилиндры с коническими крышами, зубцы, ворота-арка, окна; поставлен на камень.
3. Водоросли: 8–12 кустов из вытянутых конусов/цилиндров, каждое растение качается синусом с разной фазой и амплитудой.
4. Декор: камни, ракушки, сундук, мелкие пузырьки-декор.
5. Помпа для воздуха: трубка с распылителем у дна, из неё поднимается поток пузырьков (маленькие сферы), всплывают и исчезают у поверхности, затем рождаются заново.

**Живность**
6. Гуппи — 6–8 штук. Форма правильная: веретенообразное тело (сфера, сжатая по одной оси), хвост-веер (плоский конус/треугольник), спинной и грудные плавники, тёмный глаз. Окраска разная: оранжевая, синяя, жёлтая, крапчатая.
7. Движение рыб: у каждой своя траектория — не круг и не одна синусоида. Используй сумму двух-трёх синусов с разными периодами по X/Y/Z, скорость и радиусы у каждой рыбы свои, рыба плавно поворачивает нос по направлению движения (lookAt на следующую точку), хвост виляет с частотой, зависящей от скорости.
8. Краб: панцирь (сфера, сплюснутая), 8 ног из сегментов (капсулы), 2 клешни, глаза на стебельках. Ходит по дну маленькими шагами, иногда останавливается и шевелит клешнями.
9. Улитки — 3 штуки: спиральная раковина (торический конус или скрученная сфера), мягкое тело, усики. Медленно ползут по стеклу и по дну, разворачиваются у краёв.

**Свет и вода**
10. Свет: мягкий верхний свет + подсветка сзади, тени включены (shadowMap PCFSoft), лёгкий туман/цвет воды голубоватый.
11. Каустика: подводные блики на дне — анимированный паттерн (шейдер или несколько прозрачных пятен с медленным смещением).

**Интерфейс**
12. Подсказка в углу: «мышь — вращать, колесо — приблизить», кнопка «Пауза / Продолжить» и переключатель «Свет вкл/выкл».
13. Адаптация под размер окна (resize), не ниже 60 fps на встроенной видеокарте: геометрия низкополигональная, объекты переиспользуются.

**Проверка перед сдачей**
- Файл открывается двойным щелчком, в консоли нет ошибок.
- Вращение и зум работают, рыбы плывут по разным траекториям, пузырьки идут от помпы, растения качаются.
- В ответе — только готовый код файла и одна строка «как открыть».

## Что проверять у модели (чек-лист приёмки)

| Пункт | Как проверить |
|---|---|
Форма рыб | видны хвост-веер, спинной и грудные плавники, глаз; тело не «шар» |
Траектории | две рыбы не идут по одной линии, повороты плавные |
Краб | панцирь, 8 ног, 2 клешни, ходит по дну |
Улитки | спиральная раковина, ползут медленно, не «висят» в воде |
Помпа | пузырьки рождаются у распылителя, всплывают вверх |
Вращение | мышью облетается вся сцена, зум колесом, нет «проваливания» сквозь стекло |
Производительность | на Intel Arc / встроенной графике стабильно, без рывков |
