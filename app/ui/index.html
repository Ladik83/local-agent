Как пользоваться

Три шага

  • Вкладка «Модели» → «Запустить» на модели с пометкой «рекомендуем». Первый запуск 10–60 секунд.
  • Вкладка «Чат» → напишите вопрос и нажмите «Отправить» (Enter).
  • Мало памяти? Кнопка «Выгрузить» вернёт её.

Два режима работы

  • Один помощник — быстро, для обычных вопросов.
  • Команда специалистов — задачу по очереди разбирают роли. Настройка — вкладка «Команда».

Откуда брать модель

  • Локально — приложение само запускает модель из папки моделей.
  • Свой сервер — LM Studio или Ollama. Жмите «Найти серверы».
  • Внешний API — облако по ключу (OpenRouter и подобные).

Нижняя панель

Кнопка «Панели» показывает модель, чаты и проекты. Внизу видно модель, память и действие.
