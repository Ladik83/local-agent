# Скины и темы «Локального агента»

Три скина × два режима (тёмный/светлый) = шесть палитр. Переключение: ⚙ → «Скин», «Тема», «Плотность». Выбор хранится в `localStorage` (`agentSkin`, `agentTheme`, `agentDensity`), режим «как в системе» следит за `prefers-color-scheme`.

## Что исправлено в этом проходе

1. **Шапка была 25 px вместо 62** — коллизия классов: `<header class="bar">` и полоса прогресса `.bar`. Прогресс переименован в `.meter` (CSS + `app.js` + `panels.js`), шапка получила свои 62 px.
2. **Жёсткие цвета мешали светлым темам**: `.mode.active` (`#1b2740`), пузырь пользователя (`#23304a`), код (`#0d1017`), дорожки полос, подсказки — переведены в переменные палитры. Раньше в светлой теме выбранный режим был тёмно-синим с тёмным текстом.
3. **Ширина вкладок**: вместо `max-width: 980px` — переменная `--view-max: 1440px`, у чата отдельно 1100 px для читаемой строки. «Модели» на 1920 теперь занимают 1440 px вместо 980.
4. **Шторка «Панели»**: высота стала переменной `--drawer-h` (по умолчанию 240 px вместо 286), сверху появилась ручка перетаскивания, высота запоминается (`agentDrawerH`).
5. **Мёртвый код удалён**: `.chatBar` (два объявления), каркас `.shell/.side/.sideHead/.sideBody` (42 строки) и функция `toggleSide()`.
6. **Мелкие кнопки** (`button.tiny`, `.chip`) подняты до минимальных 32 px — по ним проще попадать.
7. **Строка «Enter — отправить»** убрана, подсказка осталась в `placeholder` поля ввода.
