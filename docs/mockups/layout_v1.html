Как устроен макет

Это рабочий макет, а не приложение. Всё сохраняется только в этом браузере.

  • Переносите блоки. Возьмите блок за заголовок и тяните в левую панель, правую или нижнюю шторку. Пунктирная рамка показывает, куда он встанет.
  • Меняйте размеры. Тяните узкие полоски между панелями. Двойной клик по полоске возвращает исходный размер.
  • Сравните варианты. Кнопки A B C сверху переключают три компоновки. У каждой свои места блоков.
  • Подберите плотность. «Компактно / Обычно / Просторно» меняют шрифт и отступы, не трогая палитру.
  • Сбросьте. Кнопка «Сбросить» возвращает всё по умолчанию.
  • Проверьте адаптив. Сузьте окно: при 1100 px правая панель уходит вниз, при 820 px панели становятся вкладками.
